## Projetos

Produtos em produção, em uso por clientes reais.

### Indicadores MedMais

Sistema web para gestão de indicadores operacionais de múltiplas bases, com controle de acesso por perfil e isolamento de dados no banco (Row Level Security).

`React` · `TypeScript` · `Supabase` · `Vite` · `Recharts`

### New Jiu Jitsu

Sistema de gestão para academias de jiu-jitsu: alunos, aulas, presença por QR code, graduações e financeiro, com suporte a múltiplas academias.

`Java 21` · `Spring Boot` · `PostgreSQL` · `React` · `Docker` · [código](https://github.com/NiltonFilhoprofessionalDEV/New-Jiujitsu)

### FireCheck

Gestão e inspeção de extintores: importação de planilhas, mapeamento em planta e conferência em campo pelo celular (PWA).

`Next.js` · `TypeScript` · `Supabase` · `PWA`

### Venda Fácil

App web mobile-first para registrar vendas, organizar entregas e otimizar a rota do dia.

`React` · `TypeScript` · `Supabase` · `PWA`
